# GoreeCloud Mesh Branding

GoreeCloud Mesh is a substantive GoreeCloud platform-system identity and coordination/governance plane.

## Current artwork status

No approved canonical GoreeCloud Mesh logo, icon, or artwork is recorded here yet.

Future Mesh identity work must be created and approved in `GoreeCloud/goreecloud-branding-assets` first. Consumer repositories may contain synchronized derivatives only when required for packaging, deployment, offline use, or performance; those copies must not become independent branding authorities.

Do not invent, substitute, or promote a generic Mesh mark merely to fill an empty branding surface. Until approved artwork exists, use the GoreeCloud Mesh name in text-only presentation where an identity treatment is required.
