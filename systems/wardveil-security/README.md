# Wardveil Security — Sentinel Fold

**Status:** Approved canonical platform-system identity candidate pending merge validation.  
**System:** Wardveil Security  
**Presentation surface:** Security Center  
**Canonical asset:** `wardveil-security-icon.svg`

## Identity

Sentinel Fold represents protective layers that wrap around a guarded core without implying that protection comes from a single perimeter or generic shield. Two asymmetric-color veil planes converge around a compact core while the negative space creates a restrained Wardveil `W` impression.

The mark is designed to communicate defense-in-depth, inspection boundaries, containment, and active protection while remaining distinct from conventional shield, lock, antivirus, or police-badge iconography.

## Geometry and visual language

- Transparent square `256 × 256` SVG source.
- Primary silhouette uses paired protective veil planes rather than a shield outline.
- Central guarded core remains visually compact so the mark survives small application-icon sizes.
- Cyan, blue, indigo, and violet gradients align with GoreeCloud's wider visual language while preserving a cooler security identity.
- White/translucent fold highlights provide dimensional separation without depending on raster effects or filters.
- No text is embedded in the visible artwork.

## Usage

Use the canonical SVG as the source for Wardveil Security system identity, Security Center branding, repository/social artwork, favicons, application icons, and other production derivatives. Raster or platform-specific exports must be generated from this source and must not redefine its geometry.

Consumer repositories may retain synchronized copies only when required for packaging, deployment, offline use, or performance. Such copies remain derivatives of `GoreeCloud/goreecloud-branding-assets`.

## Authority boundary

Wardveil Security is GoreeCloud's platform-wide security and protection system. The Sentinel Fold artwork identifies that system; it does **not** itself prove antivirus coverage, malware-detection capability, security posture, runtime protection state, compliance, production acceptance, or any other technical claim. Public claims must remain tied to current implementation and evidence.
