# GoreeCloud Mobile Branding Assets

This directory defines the authoritative mobile visual asset contracts for GoreeCloud Android and GoreeCloud OS Mobile.

Current governed asset families:

- `WALLPAPER-SYSTEM.md` — first-party GoreeCloud/Glaze UI wallpaper family and Android integration requirements.
- `ANDROID-ICON-SYSTEM.md` — unified adaptive icon construction and acceptance requirements for first-party Android apps.

Master artwork and approved derivatives must be added here as they are produced. Product repositories consume approved assets; they are not independent branding authorities.
