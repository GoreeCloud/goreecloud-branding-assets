# GoreeCloud Mobile Branding Assets

This directory is the authoritative mobile visual asset source for GoreeCloud Android and GoreeCloud OS Mobile.

Current governed asset families:

- `WALLPAPER-SYSTEM.md` — first-party GoreeCloud/Glaze UI wallpaper family and Android integration requirements.
- `ANDROID-ICON-SYSTEM.md` — unified adaptive icon construction and acceptance requirements for first-party Android apps.
- `wallpapers/` — current first-party wallpaper master artwork.

## Current wallpaper masters

The following master assets are now present and are intended for Android derivative/export work:

- `wallpapers/goreecloud-living-glaze.svg` — primary GoreeCloud OS Mobile Home direction; dark Living Glaze atmosphere with restrained GoreeCloud blue and aqua illumination.
- `wallpapers/goreecloud-graphite.svg` — dark graphite/smoke Glaze treatment optimized for strong icon contrast.
- `wallpapers/goreecloud-pearl.svg` — light pearl/frost treatment for light environments.
- `wallpapers/goreecloud-mesh.svg` — abstract connected-node treatment representing GoreeCloud Mesh and the broader interconnected GoreeCloud ecosystem.

These are GoreeCloud-native assets. They do not reproduce or derive from LineageOS wallpaper artwork.

The SVG files are high-resolution-independent master sources at a 1440 × 3200 portrait artboard. Android PNG/WebP exports, crops, picker thumbnails, and default-wallpaper resources must be generated from these current masters rather than becoming independent artwork authorities.

Product repositories consume approved assets; they are not independent branding authorities.
